# Global AI Valley (GAiV) 🌐

An editorial, immersive web experience built for **Global AI Valley** — connecting researchers, startups, and institutions to accelerate global AI innovation.

---

## ✨ Features

- **Interactive 3D Globe**: Built with Three.js / WebGL with custom particle shaders and dynamic camera controls.
- **Cinematic Experience**: Custom cinematic introductory reveal screen and fluid Lenis inertial scrolling.
- **Modern Kinetic Typography**: Cormorant Garamond editorial serif paired with crisp Inter UI typography.
- **Interactive Ecosystem**: Dynamic showcase for AI research, venture ecosystems, and impact milestones.
- **Responsive & Performant**: Powered by React 19, Vite, and Oxlint for ultra-fast load times.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **3D / WebGL**: [Three.js](https://threejs.org/)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Pranay-k1408/Global-AI-Valley-.git

# Navigate to project directory
cd Global-AI-Valley-

# Install dependencies
npm install

# Start the development server
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
npm run preview
```
